# 六爻卜卦

依《黃金策》15大類別進行占問分析的六爻占卜工具。**完全本地運算，永久免費，無需任何 API。**

## 功能
- 起卦輸入（陽爻／陰爻／老陽／老陰），自動計算農曆日干支、月干支
- 空亡、月破自動標示，伏神自動推算
- 15大占問類別，每類依用神／原神／忌神／仇神給出專屬分析：
  - 天時、年時、婚姻、求財、功名仕途、求職謀事
  - 行人音訊、出行遠行、疾病、訴訟官非、買賣交易
  - 求子嗣、宅舍居住、六畜牲口、尋人走失
- 深度斷法（《黃金策》《卜筮正宗》《增刪卜易》）：
  - 動爻化爻：化進神／化退神、回頭生／回頭剋、化墓／化絕
  - 卦體六沖六合（先散後聚、先易後難等格局判斷）
  - **應期判斷**：空亡以出空斷、月破以出月斷、安靜以沖動斷、發動以合值斷
  - 每類別給出明確占斷結論

## 使用
直接開啟 `index.html`，或部署至 GitHub Pages。

## GitHub Pages 部署
1. 上傳 `index.html` 與 `README.md`
2. Settings → Pages → Branch: main → Save
3. 訪問 `https://<帳號>.github.io/<repo名>/`

## 技術
純 HTML / CSS / JavaScript，無外部依賴。所有斷法內建於本地引擎，不呼叫任何 API。
